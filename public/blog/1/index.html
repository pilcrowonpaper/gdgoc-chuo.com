公式サイトを作りました！

GDGoC Chuo University の公式サイトを作りました！サイト自体は去年の11月頃からありましたがやっとブログを追加しました。すでに記事が4つ公開されています。

GDGoC Chuo University はウェブやモバイルアプリの開発を中心に活動している中央大学のサークルです。このサイトではメンバーが書いたブログ記事の公開とプロジェクトの紹介を行っています。

ウェブ開発に触れるサークルは公式サイトを作りべきだと思ってます。ただ実際公式サイトがあるサークルが意外と少なかったのでこれからもっと増えていってほしいです。

このサイトは Astro で作った静的サイトです。昔から Astro を使っていますが、やっぱり使いやすい。生成された HTML は Cloudflare Workers で Static Assets としてデプロイしています。

僕はバックエンドをメインにやってるのでそんなに CSS とかアニメーションを使いたいと思わないのですが、かっこいい「何か」が欲しかったのででっかい 「GDGoC Chuo」の ASCII アートとアニメーションを加えました。（実はアニメーションのパターンが複数あります！）

アニメーションは DOM とテキストだけでやっています。

まず Blender でいい感じの 3D テキストを作って、怪しいサイトで画像を ASCII アートに変換しました。

あとは初期値の無の文字列を ASCII アートの文字列になるまで文字を変えていくだけです。

これでも悪くないパフォーマンスなのでブラウザーと JavaScript ってすごい。HTML と CSS 使っているだけなので簡単にレスポンシブなデザインにできました。 calc() などを使ってページの大きさに合わせてフォントサイズを設定しています。 

font-size: min(calc(100vw / 200 * 1.5), calc(80vh / 60), 0.7rem);
